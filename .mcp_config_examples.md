# ERPNext Assist - MCP Server Configuration Examples

This directory contains example configurations for integrating the ERPNext Assist MCP server
with various AI clients and tools.

## Claude Desktop Configuration

Location: `~/Library/Application Support/Claude/claude_desktop_config.json` (Mac)
         `%APPDATA%\Claude\claude_desktop_config.json` (Windows)

```json
{
  "mcpServers": {
    "erpnext-assist": {
      "command": "python",
      "args": ["-m", "erpnext_assist.mcp_server.server"],
      "cwd": "/path/to/frappe-bench/apps/erpnext_assist",
      "env": {
        "FRAPPE_SITE": "your-site-name",
        "MCP_TRANSPORT": "stdio"
      }
    }
  }
}
```

## HTTP Mode Configuration

For web-based clients or remote access:

```bash
# Set environment variable
export MCP_TRANSPORT=streamable-http
export MCP_PORT=8000

# Run server
python -m erpnext_assist.mcp_server.server
```

Then configure clients to connect to: `http://localhost:8000`

## Ollama Integration (Offline AI)

Run locally with Ollama models:

```bash
# Install Ollama
curl -fsSL https://ollama.com/install.sh | sh

# Pull a model
ollama pull llama2

# Start Ollama
ollama serve

# Configure your MCP client to use Ollama endpoint
# The MCP server will work with any AI that can call its tools
```

## Custom Python Script Integration

```python
import subprocess
import json

# Start the MCP server as a subprocess
server = subprocess.Popen(
    ["python", "-m", "erpnext_assist.mcp_server.server"],
    stdin=subprocess.PIPE,
    stdout=subprocess.PIPE,
    stderr=subprocess.PIPE,
    cwd="/path/to/frappe-bench/apps/erpnext_assist"
)

# Send JSON-RPC requests to the server

```

## Environment Variables

Available environment variables:

- `MCP_TRANSPORT`: Transport type (`stdio` or `streamable-http`)
- `MCP_PORT`: Port for HTTP mode (default: 8000)
- `FRAPPE_SITE`: ERPNext site name (if needed)
- `DEBUG`: Enable debug logging (`true` or `false`)

## Security Considerations

### Local Development
- Default stdio mode is secure for local development
- No network exposure

### Production/Remote
- Use HTTPS for HTTP mode
- Implement authentication/authorization
- Restrict network access
- Use environment variables for sensitive data

## Testing the Configuration

```bash
# Test the server starts correctly
python -m erpnext_assist.mcp_server.server

# Should output:
# Loaded X user-drafted tools
# MCP server running on stdio transport
```

## Troubleshooting

### Server Won't Start
1. Check Python path: `which python`
2. Verify dependencies: `pip install -r requirements.txt`
3. Check permissions on the directory
4. Review error logs

### Tools Not Available
1. Ensure tools are enabled in ERPNext
2. Restart the MCP server
3. Restart the AI client
4. Check server logs for errors

### Connection Issues (HTTP mode)
1. Check firewall settings
2. Verify port is not in use: `lsof -i :8000`
3. Test with curl: `curl http://localhost:8000`

## Advanced Configuration

### Custom Port (HTTP mode)
```bash
export MCP_PORT=9000
python -m erpnext_assist.mcp_server.server
```

### Multiple Sites
Run separate servers for different ERPNext sites:

```bash
# Site 1
FRAPPE_SITE=site1 MCP_PORT=8001 python -m erpnext_assist.mcp_server.server &

# Site 2
FRAPPE_SITE=site2 MCP_PORT=8002 python -m erpnext_assist.mcp_server.server &
```

### Systemd Service (Linux)

Create `/etc/systemd/system/erpnext-mcp.service`:

```ini
[Unit]
Description=ERPNext Assist MCP Server
After=network.target

[Service]
Type=simple
User=frappe
WorkingDirectory=/path/to/frappe-bench/apps/erpnext_assist
Environment="MCP_TRANSPORT=streamable-http"
Environment="MCP_PORT=8000"
ExecStart=/usr/bin/python -m erpnext_assist.mcp_server.server
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

Enable and start:
```bash
sudo systemctl enable erpnext-mcp
sudo systemctl start erpnext-mcp
```
